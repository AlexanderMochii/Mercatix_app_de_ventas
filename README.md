# Mercatix - App de ventas

## Descripción
plataforma web diseñada como un prototipo funcional que servirá de base para el 
desarrollo futuro de un programa de escritorio y una aplicación móvil. Su objetivo principal es 
facilitar que pequeños negocios ganen mayor visibilidad y competitividad en el mercado digital, 
ofreciéndoles herramientas para potenciar sus ventas y mejorar la interacción con sus clientes.

## Estructura del proyecto
- `index.html` - Página de inicio
- `login.html` - Página de inicio de sesión
- `login2.html` - Página de registro
- `css/` - Archivos CSS
- `js/` - Archivos JavaScript
- `imag/` - Imágenes
- `.github/workflows/` - Workflows de GitHub Actions

## Tecnologías
- HTML semántico
- CSS personalizado
- JavaScript funcional
- Git y GitHub
- GitHub Actions para CI/CD
- GitHub Pages para publicación

## Contribución
- Trabajar en la rama `desarrollo` para nuevas funciones o correcciones.
